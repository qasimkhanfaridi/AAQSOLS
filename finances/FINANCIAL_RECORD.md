## 5. How to Maintain & Update Finances

Run the Node.js CLI tool anytime from PowerShell or CMD:

```powershell
# Show summary & partner settlement ledger
node D:\AAQSOLS\finances\aaqsols_finance.js summary

# Show project contracts & domains matrix
node D:\AAQSOLS\finances\aaqsols_finance.js projects

# Add a new expense (Kharcha)
node D:\AAQSOLS\finances\aaqsols_finance.js add-expense "Office Capex" "Item Name" 5000 "qasim"

# Add a client advance or milestone
node D:\AAQSOLS\finances\aaqsols_finance.js add-inflow "rehman_travels" "Initial Advance" 20000 "qasim"
```
