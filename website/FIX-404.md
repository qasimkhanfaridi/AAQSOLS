# FIX aaqsols.com 404 Error

## Problem
Your domain has **2 A records**. One points to GoDaddy/Cloudflare (`160.153.0.104`) which returns **404**.
Browser randomly hits the wrong server.

---

## Fix in GoDaddy DNS (5 minutes)

Go to: **GoDaddy → aaqsols.com → DNS**

### DELETE this record:
| Type | Name | Data | Action |
|------|------|------|--------|
| A | @ | **160.153.0.104** | **DELETE** |

### KEEP only this A record:
| Type | Name | Data |
|------|------|------|
| A | @ | **75.2.60.5** |

### CHANGE www CNAME:
| Type | Name | Old Value | New Value |
|------|------|-----------|-----------|
| CNAME | www | aaqsols.com | **YOUR-SITE.netlify.app** |

Get YOUR-SITE name from Netlify → Domain management (e.g. `aaqsols.netlify.app`)

### OPTIONAL — delete if present:
| Type | Name | Data | Why |
|------|------|------|-----|
| CNAME | _acme-challenge | cloudflare.com | Causes Cloudflare conflict |

**Do NOT delete MX records** (Zoho email).

---

## Fix in Netlify

1. [app.netlify.com](https://app.netlify.com) → your site
2. **Domain management** → ensure both added:
   - `aaqsols.com`
   - `www.aaqsols.com`
3. Set **Primary domain** = `aaqsols.com`
4. **HTTPS** → Force HTTPS → ON

---

## Redeploy website (with CSS fix)

1. Netlify → **Deploys** tab
2. Drag folder: `D:\AAQSOLS\website`
3. Wait 30 seconds

---

## Test after 15 minutes

- https://aaqsols.com
- https://www.aaqsols.com (should redirect to aaqsols.com)

Hard refresh: **Ctrl + Shift + R**

## Still 404?

Clear browser cache or try incognito window.
Or run in PowerShell:
```
ipconfig /flushdns
```
