# Fix aaqsols.com 404 / wrong content

## Cause

Two (or more) servers answered for the same domain:

- GoDaddy / IIS (`160.153.x`) — old or missing files  
- Netlify or another CDN — different deploy  

Browsers hit different IPs → **404**, broken careers page, or old HTML.

## Fix (use Cloudflare Pages only)

Follow **`CLOUDFLARE-PAGES.md`** end to end.

Quick DNS rules after Cloudflare Pages is live:

1. **One** hosting path: Cloudflare Pages custom domain for `aaqsols.com`
2. **Remove** A record `@` → `160.153.0.104`
3. **Remove** Netlify A/CNAME for `@` / `www`
4. **Keep** MX records for email

## Test

```text
https://aaqsols.com/
https://aaqsols.com/careers.html
https://www.aaqsols.com/   → should redirect to apex
```

Hard refresh: **Ctrl + Shift + R**  
DNS cache: `ipconfig /flushdns` (Windows)
